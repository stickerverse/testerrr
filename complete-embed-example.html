🎨 StickerVerse Editor Integration

Complete example of embedding the StickerVerse sticker editor

Controls

📋 Integration Steps:

  1. Include CSS: stickerverse_sticker_editor.css
  2. Include React 18 libraries
  3. Include editor bundle: simple-sticker-editor.umd.js
  4. Call SimpleStickerEditor.init()

🔧 API Usage:

// Initialize
const editor = SimpleStickerEditor.init(
  'container-id', 
  { debug: true }
);

// Cleanup
editor.unmount();
