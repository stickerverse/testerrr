🎨 StickerVerse Editor - Simple Integration

This is a minimal example of embedding the StickerVerse sticker editor.

Click "Initialize Editor" to load the sticker editor

Integration Code:

<!-- Include CSS -->
<link rel="stylesheet" href="./dist/stickerverse_sticker_editor.css">

<!-- Include React dependencies -->
<script src="https://unpkg.com/react@18/umd/react.production.min.js"></script>
<script src="https://unpkg.com/react-dom@18/umd/react-dom.production.min.js"></script>

<!-- Include StickerVerse Editor -->
<script src="./dist/simple-sticker-editor.umd.js"></script>

<!-- Initialize -->
<script>
  const editor = window.SimpleStickerEditor.init('container-id', {
    theme: 'light',
    width: '100%',
    height: '600px'
  });
</script>
